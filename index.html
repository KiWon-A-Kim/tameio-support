타미오 Tameio

직접 적는 가계부. 데이터는 기기 안에.

은행이나 카드사에 연결하지 않습니다. 적은 것만 기록하고, 적은 것은 기기를 떠나지 않습니다. 계정도 로그인도 없습니다.

  • 수입·지출·이체·카드대금·환불을 복식부기로 정확히 기록
  • 결제 알림 문자를 붙여넣어 입력 채우기 — 문자함을 읽지 않습니다
  • 영수증 촬영과 기기 안 글자 인식
  • 예산 기간·이월, 통계, 다중 통화
  • 백업 파일 만들기·복원, 기기 간 직접 전송(암호화)
  • Face ID 앱 잠금

현재 지원 기기는 iPhone 과 iPad 입니다.
